# 一键发布.exe 使用说明
===============================================

## 这是什么
双击一次，自动完成 5 件事：
  ① 提交所有代码改动到 git（自动生成提交说明，如"更新页面、后端"）
  ② 更新 index.html 的缓存版本号（格式：日期-最新提交号，自动同步 preload/link）
  ③ 提交版本号变更
  ④ 推送代码到 GitHub
  ⑤ 提示你在 PythonAnywhere 同步服务器的最后一步

## 什么时候用
改完任何代码（CSS/JS/HTML/Python/图片素材）之后，想发布上线时。

## 怎么用
  1. 双击「一键发布.exe」
  2. 看窗口里的步骤提示（黑窗口，跑完自动关闭/停留）
  3. 按提示去 PythonAnywhere 点一下同步，完成

## 正常运行的标志（窗口内容示例）
  ✅ 已提交: 自动发布：更新页面、后端（08-17 08:12）
  ✅ 版本号已更新: ?v=20260817-xxx → v=20260817-xxxxxxx
  ✅ 已推送至 GitHub（分支: main）
  🎉 一键发布完成！

## 常见情况处理
| 情况 | 说明 |
|---|---|
| 提示"没有检测到任何改动" | 你没改文件（或没保存），无需发布 |
| 推送失败（网络不通） | GitHub 在国内不稳定，本地提交已保存不会丢。检查网络/代理，或等一会再双击一次重试 |
| 推送失败（未登录） | 首次使用需在命令行执行一次 `git push origin main` 完成 GitHub 登录（之后记住密码即可） |
| 版本号提交后显示 404 | 部署后浏览器按 Ctrl+F5 强制刷新一次 |

## 原理说明（了解即可）
- 版本号 = 日期-最新git提交号，每次发布自动变，用户浏览器自动拿到新文件
- 代码先提交、后改版本号、再提交，保证版本号永远对应本次发布的提交
- 数据库、订单文件、上传图片已被 .gitignore 排除，不会误提交

## 其他文件
- 更新版本号.py：只更新版本号不提交（手动场景用）
- 一键发布.py：本工具的源代码（打包成 exe 了，可删可留）
